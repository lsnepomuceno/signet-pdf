# Signet PDF 2.x

**This is the archived documentation for the 2.x line, frozen at `2.0.1`.** It
is the prose that shipped with that release, published as it stood.

For the line that is current now, use the version control in the navigation, or
go to the [current documentation](https://lsnepomuceno.github.io/signet-pdf/).

2.x is the release that left the framework behind: the entry point became a
fluent builder, configuration became value objects, and the container went away.
What 3.x changed on top of that is in
[Upgrading](https://lsnepomuceno.github.io/signet-pdf/releases/upgrade).
